\# DecodeLabs Internship - Project 2



\## AWS EC2 Web Server Deployment



This repository contains my Project 2 submission for the DecodeLabs Cloud Computing Internship.



The objective of this project was to launch an AWS EC2 Ubuntu server, install and configure the Apache Web Server, and host a custom webpage accessible through the EC2 public IP address.



\## Technologies Used



\- Amazon Web Services (AWS)

\- Amazon EC2

\- Ubuntu Linux

\- Apache Web Server

\- SSH

\- GitHub



\## Project Steps Completed



\- Created an EC2 Ubuntu instance

\- Connected to the server using SSH

\- Updated Ubuntu packages

\- Installed Apache Web Server

\- Configured the website files

\- Hosted a custom HTML webpage

\- Verified the website using the EC2 public IP address
